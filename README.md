# Mini-Atoms 一句话生成网页

笔试 Demo：通过自然语言生成可交互小网页，并在沙盒中实时预览。

## 在线体验
推送到 GitHub 后可用 GitHub Pages / Vercel 部署，本地直接打开 index.html 也可体验。

## 功能
- 一句话生成：番茄钟 / 待办清单 / 个人名片 / 通用落地页
- 预览 / 代码切换，iframe 沙盒渲染
- 追问修改 + 快捷追问 chips（换个配色 / 深色模式 / 加点动画）
- 历史版本：预览、回滚、删除，localStorage 持久化
- 一键复制代码、下载独立 HTML

## 部署
- Vercel：导入本仓库，框架选 Other，输出目录为 `/`
- GitHub Pages：Settings -> Pages -> Deploy from branch -> main / root

## 工具链
全程使用 Meta AI vibe coding 构建。
